# Dominion525 Tap

## How do I install these formulae?

`brew install dominion525/tap/<formula>`

Or `brew tap dominion525/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dominion525/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
